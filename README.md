# Bayt al-Ilm — بيت العلم

Islamic fatwa website with AI chatbot powered by Google Gemini.

---

## Setup

```bash
npm install
npm run dev
```

---

## Adding your Gemini API key

### Local development
Create a `.env.local` file in the root:
```
GEMINI_API_KEY=your_key_here
```

### On Netlify (production)
1. Go to your Netlify site dashboard
2. Site settings → Environment variables
3. Add: `GEMINI_API_KEY` = your key
4. Redeploy

**Never commit your API key. The .env.local file is gitignored.**

## Adding PDF books to the knowledge base

### Step 1 — Install pdfjs (one time only)
```bash
npm install
```

### Step 2 — Process a PDF
```bash
node scripts/processPdf.js "path/to/your/book.pdf" "Book Title"
```

Example:
```bash
node scripts/processPdf.js "./books/fiqh-sunnah.pdf" "Fiqh al-Sunnah"
node scripts/processPdf.js "./books/riyadh-saliheen.pdf" "Riyadh al-Saliheen"
```

This extracts all text, splits it into chunks, and saves to `data/chunks.json`.

### Step 3 — Commit and deploy
```bash
git add data/chunks.json
git commit -m "Add book: Fiqh al-Sunnah"
git push
```

Netlify will auto-redeploy.

### To replace all books
Delete `data/chunks.json`, then run the script again for each book.

### To add more books
Just run the script again — it appends to existing chunks.

## Deploy to Netlify

1. Push this folder to a GitHub repo
2. Connect to Netlify (New site → Import from Git)
3. Build command: `npm run build`
4. Publish directory: `.next`
5. Add the Netlify Next.js plugin — Netlify usually auto-detects it
6. Add your `GEMINI_API_KEY` environment variable
7. Deploy

## Getting a free Gemini API key

1. Go to https://aistudio.google.com/
2. Sign in with your Google account
3. Click "Get API key"
4. Create a new key — it's free with generous limits
5. Add it to Netlify environment variables as `GEMINI_API_KEY`
